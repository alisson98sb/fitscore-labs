# FitScore

Semantic ATS scoring platform focused on evaluating compatibility between resumes and job descriptions using:

- lexical matching
- embeddings
- LLM evaluation
- explainable AI

## Tech Stack
- Python
- FastAPI
- PostgreSQL + pgvector
- Spring AI
- React
- Docker

## Goals
- Compare lexical vs semantic matching
- Improve ATS explainability
- Reduce false negatives in hiring pipelines
